# Finance Analysis Dashboard — Power BI

## Project Overview

This project presents a Finance Dashboard designed to monitor income, expenses, savings, and financial performance across different months and years.
The dashboard provides a consolidated view of financial trends, savings allocation, expense categories, and key financial indicators.

## Dashboard Preview

Finance Dashboard (finance-dashboard.png)

## Key Performance Indicators (KPIs)
- **Income:** Total income for the selected period.
- **Expenses:** Total expenses across spending categories.
- **Savings:** Total savings accumulated.
- **Savings Percentage:** Proportion of income retained as savings.
- **Income Month-over-Month Change:** Monthly income growth or decline.
- **Expense Month-over-Month Change:** Monthly expense growth or decline.

## Dashboard Visualizations
### 1. Financial Trend Analysis
A monthly trend chart comparing expenses, income change, savings percentage, and the target.

### 2. Expense Distribution
A doughnut chart showing the distribution of expenses across categories, including rent, groceries and food, EMIs, health, leisure, shopping, and travel.

### 3. Savings Distribution
A doughnut chart illustrating the allocation of savings across liquid cash, mutual funds, emergency funds, and fixed deposits.

### 4. Financial Summary Matrix
A detailed matrix comparing income, expenses, and savings by financial year and category.

## Interactive Features
- Year selection
- Month-year filtering
- Financial category breakdowns
- Monthly financial performance comparisons

## Tools and Technologies
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Data visualization and financial KPI analysis

## Project Objective
To provide a clear overview of financial performance, identify major spending categories, monitor savings, and support data-driven financial decisions.
